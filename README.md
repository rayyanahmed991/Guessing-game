The program generates a random secret number between 1 and a user-defined upper limit. The player must guess the secret number, receiving feedback after each attempt.

uses a hot-and-cold temperature feedback system, which tells the player whether their guesses are getting closer to or further away from the secret number.

Features:
Randomly generates a secret number within the chosen range.

Allows the player to enter guesses until the correct number is found.

Validates user input to ensure guesses and the upper limit are positive integers.

Provides temperature-based feedback:
Freezing
Cold
Warm
Hot
Boiling

Compares consecutive guesses to determine whether the player is getting warmer or colder.

Uses previous and current guess distances to track progress.

Dynamically adjusts temperature ranges based on the selected upper limit.
